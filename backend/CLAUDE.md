# 财务尽调多智能体系统 —— 项目规则

> 本文件记录本项目的长期约定。后续所有开发（包括 Claude Code）都必须遵守。

## 一、项目目标

开发一个财务尽调多智能体（Multi-Agent）系统，由财务、法务、业务等子智能体分工协作，
辅助完成财务尽职调查中的资料提取、风险识别与分析汇总。

## 二、技术栈

- **Python 3.10 或更高版本**。
- **Streamlit**：负责网页前端界面。
- **大模型调用**：直接调用大模型 API，接口格式兼容 OpenAI SDK。
- **模型服务商**：DeepSeek。
- **PDF 处理**：使用 pypdf 等工具提取 PDF 中的文字。
- **本地配置**：使用 python-dotenv 从项目根目录的 `.env` 文件读取环境变量。

## 三、目录职责

- `app.py`：Streamlit 前端入口，负责页面展示和用户交互。
- `agents/`：存放财务、法务、业务等子智能体的代码。
- `utils/`：存放 PDF 提取、文本清洗等可复用的工具函数。
- `requirements.txt`：记录项目运行所需的 Python 依赖。

## 四、必须遵守的开发规则

1. **所有代码必须包含详细的中文注释。**
   - 注释要解释“这段代码做什么、为什么这样做”，不能只把代码翻译一遍。
   - 关键的函数、参数、返回值、异常处理都要有中文说明。

2. **所有 API Key 必须从环境变量读取，绝对禁止硬编码在代码中。**
   - DeepSeek 的 Key 统一使用环境变量名 `DEEPSEEK_API_KEY`。
   - 本地开发时把 Key 写在项目根目录的 `.env` 文件中。
   - `.env` 文件不得提交到代码仓库，也不得发给其他人。
   - 不要把 Key 写进日志、提示词、页面输出、截图或报错信息。

3. **新增依赖时必须同步更新 `requirements.txt`，并写明中文用途注释。**

4. **不擅自更换技术栈。** 如果确实需要更换，必须先向用户说明原因，
   给出 2～4 个候选方案并等待用户确认。

## 五、本地启动方式（Windows）

```powershell
# 进入项目目录
cd "C:\Users\84981\DD agent"

# 创建项目专用虚拟环境
py -m venv .venv

.\.venv\Scripts\Activate.ps1

python -m pip install -r requirements.txt

```
